Would you like learn about OOS?

Closing Applications

  1. Move your mouse cursor to the bottom left hand corner of the screen
  2. Select the Home button to close
  3. Select the People button to minimize
  4. Select the share button to quickly share the app with a friend

Installing Applications

  1. Open the appstore from the Plaza
  2. Select "Get" for the application
  3. And Choose a slot to install the app to

Learn about people

  1. Find the person you would like to learn about
  2. Click on them
  3. And OOS will tell you what game they are playing

Changing your Plaza

  1. Select Settings
  2. Find where it says Group and change it
  3. (Only people with that same Group will appear)
